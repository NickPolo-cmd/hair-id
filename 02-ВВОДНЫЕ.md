# HAIR ID — зафиксированные вводные

Обновлено: 2026-09-04. Это источник правды по решениям. Всё, что здесь записано, считается утверждённым.

---

## 1. Бизнес-модель

Hair ID — **зонтичный бренд**, два направления:

| Направление | Что это | Статус |
|---|---|---|
| **Hair ID Studio** | Услуги мастера по волосам: 12 процедур | Работает сейчас |
| **Hair ID Shop** | Средства для волос и косметика: сначала перепродажа чужих брендов, затем собственная марка | Запуск в течение месяца |

**Связка направлений (ядро бизнес-модели):**
диагностика в студии → индивидуальный протокол → процедура → **домашний уход из своего магазина** → повторный визит.
Магазин не сбоку от услуг, а следствие услуг. Это даёт повторные продажи и оправдывает наценку.

**Каналы продаж товара:** свой сайт · Wildberries и Ozon · продажа прямо в студии · Авито и соцсети.

## 2. Формат работы мастера

- Своя **студия-кабинет** (отдельное помещение под приём), не «на дому у мастера».
- Речь от первого лица: **«я»** — личный бренд мастера.
- Локация: д. Нижние Осельки, Лесколовское СП, Всеволожский р-н, Ленинградская обл.
- Продвижение — по всем ближним населённым пунктам + север Санкт-Петербурга.

## 3. Смысловое ядро бренда

**ID = Identity.** «У каждых волос свой ID».

Идея: волосы — не «тип по учебнику», а индивидуальный набор параметров (пористость, плотность, история окрашиваний, состояние кожи головы). Сначала определяем ID, потом подбираем протокол и уход. Отсюда:

- в студии — диагностика перед любой процедурой и честный отказ, если процедура не поможет;
- в магазине — подбор средств под ID, а не «купите вот это, всем подходит»;
- на сайте — интерактивный подбор по задаче (логика взята у профлакон.рф);
- в перспективе — карта волос клиента, история процедур, персональная схема ухода.

## 4. Визуальное направление

Задано логотипом: **золото на глубоком тёмно-зелёном**.

- Основа — тёплый минимализм (много воздуха, спокойная типографика, ничего лишнего),
  но в фирменной гамме зелёный + золото, а не в белой.
- Ощущение: дорого, спокойно, по-человечески. Не аптека, не гламур.
- Для карточек товара и каталога понадобится светлая тема (кремовая) — тёмный фон плохо
  работает для e-commerce и маркетплейсов. Значит: **две темы, одна система токенов.**

## 5. Логотип

- Файл: `assets/logo/hair-id-logo-original.jpg` (JPEG, 16 КБ, растр, тёмный фон).
- Композиция: монограмма H+D со сплетёнными штрихами, сквозь неё проходит стилизованная прядь
  (три волнистые линии), подпись `HAIR ID` капителью с большой разрядкой.
- Цвет: золотой металлический градиент на тёмно-зелёном фоне.

**Открытые вопросы по логотипу:**
1. Знак читается как **HD**, а бренд называется **Hair ID**. Нужно закрепить трактовку
   (H + iD) в брендбуке, иначе воспринимается как несостыковка.
2. Нужен **векторный исходник** (SVG / AI / EPS / PDF). Растр 16 КБ не годится для вывески,
   упаковки, печати и карточек маркетплейсов.
3. Нужны варианты: на светлом фоне, монохромный (один цвет), только знак без подписи,
   горизонтальная компоновка, иконка для аватарки.

## 6. Референсы

| Источник | Что берём | Что НЕ берём |
|---|---|---|
| **профлакон.рф** | Логику: «подбери уход под свою задачу», блок ценностей, бесплатный подбор от специалиста, спокойную подачу, структуру каталога | Визуал (белый + розовый, Inter), тексты, ассортимент |
| **tilesuite.lu** | Механику анимаций: инерционный скролл, появление блоков со стаггером, пословное раскрытие заголовков, параллакс, бегущую строку с реакцией на скорость скролла, морфинг логотипа, выезжающий футер, кастомный курсор, стадии загрузки | Немецкую подачу, плиточную тематику, палитру |

## 7. Разобранная механика анимаций tilesuite.lu

Сайт на WordPress с самописным движком (без GSAP, без Lenis). Ключевые приёмы:

| Приём | Как сделано |
|---|---|
| Инерционный скролл | Контейнер `#phatscroll` двигается через `top: -lerp(prev, scrollY, 0.09)` в `requestAnimationFrame`; body получает высоту контента |
| Появление блоков | Классы `do-anim*` → при попадании в вьюпорт получают `is-animated`, стаггер 30 мс между соседями |
| Заголовки по словам | `.word-lettering` разбивается на `<span class="word">` с переменными `--word-index` и `--word-random` |
| Стадии загрузки | `has-landed` (200 мс) → `has-loaded` (800 мс) → `has-displayed` (1600 мс) на `<body>` |
| Морфинг логотипа | Ширина большого логотипа в герое пересчитывается по скроллу до ширины логотипа в шапке, затем класс `home-switch-logo` |
| Выезжающий футер | `translateY(0.4 × (высота документа − скролл − высота окна))` |
| Бегущая строка | Скорость = базовая + `|разница скролла| / 40` — строка ускоряется при быстром скролле |
| Кастомный курсор | Позиция через `lerp(prev, mouse, 0.12)`, только шире 768 px |
| Sticky-секции | Вручную: `.sticky-parent` + `.sticky-el` + `data-sticky-top` |
| Фокус в меню | `.fade-siblings` — при наведении на пункт остальные тускнеют |
| Переходы между страницами | Подгрузка контента без перезагрузки, с подменой мета-тегов |

бренды косметики, контакты, график, фото, домен. Пока эти данные не придут, в текстах стоят
плейсхолдеры вида `[цена]`, `[имя]`, `[бренд]` — они помечены и собраны в отдельный список.
