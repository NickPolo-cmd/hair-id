# Телеграм-бот Hair ID — как он устроен и что с ним делать

Бот: **@hairidspb_bot**. Делает две вещи.

## 1. Отвечает на вопросы о студии

Отвечает **только по файлу `знания.md`**, который лежит рядом. Чего в этом файле нет —
бот говорит «не знаю» и предлагает написать или позвонить. Он не выдумывает цены,
не ставит диагноз и не записывает клиентов сам.

**Правьте `знания.md` руками.** Поменяли цену, добавили услугу, сменился график —
открыли файл, поправили, сохранили. Перезапускать бота не нужно, он перечитывает
файл на каждом сообщении.

Ответы идут через OpenRouter на бесплатных моделях. Основная —
`inclusionai/ling-3.0-flash-sante:free`, если она занята, бот сам переходит на запасные.
Ключ берётся из настроек системы, в коде и в переписке его нет.

## 2. Собирает товары из темы «Товары»

Всё, что пишут в теме «Товары» группы Hair ID, бот складывает в `данные/товары.json`,
а снимки — в `фото-товаров/`. Он сам находит нужную тему по названию и запоминает её.

Понимает и короткую запись, и подробную:

```
Бессульфатный шампунь
Бренд: Keune
Объём: 300 мл
Цена: 1290 ₽
Кому: после кератина и ботокса
Не подходит: при жирных корнях как единственное средство
```

Достаточно названия и цены — остальное можно дописать позже.

**Важно про историю.** Бот видит только то, что написано **после** его появления в группе.
Сообщения, отправленные до этого, Telegram ему не отдаёт — это устройство платформы,
а не настройка.

Самый простой способ передать старые товары — **переслать их боту в личку**:

1. Откройте тему «Товары».
2. Долгое нажатие на первом сообщении → выделить → отметьте все нужные.
3. «Переслать» → выберите **@hairidspb_bot**.

Бот принимает пересылки как товары и отвечает «Принял в базу товаров» на каждое.
Пересылать можно и текст, и фотографии с подписями.

Второй способ, если сообщений очень много: выгрузить историю
(в Telegram на компьютере: правой кнопкой по чату → «Экспорт истории чата» →
формат JSON) и положить файл `result.json` в папку `импорт/` проекта.

## Номенклатура для поставщика

```
node tools/номенклатура.mjs
```

Соберёт в папку `поставщик/` таблицу со всеми полями, которые спрашивает
поставщик (включая коды ТН ВЭД и целевую закупочную цену), и готовое
письмо-запрос — по-русски для Беларуси и по-английски для Китая.

## Как перенести товары на сайт

```
node tools/товары-в-магазин.mjs
```

Скрипт сам найдёт источник — то, что собрал бот, или выгрузку, или простой список
текстом в `импорт/товары.md` — разложит по полям, скопирует фотографии и запишет
`site-shop/js/products.data.js`. Каталог магазина подхватит его сам.

## Команды бота

- `/start` — короткое приветствие
- `/товары` — сколько товаров в базе и нашлась ли тема
- `/итог` — то же самое, но прямо в теме «Товары»

## Запуск

Разово, пока открыт терминал:

```
cd ~/Desktop/Волосы/bot && node bot.mjs
```

Чтобы бот поднимался сам при включении компьютера и перезапускался после сбоя —
поставьте его в автозапуск (файл `автозапуск.plist` уже готов):

```
cp ~/Desktop/Волосы/bot/автозапуск.plist ~/Library/LaunchAgents/ru.hairid.bot.plist && launchctl load ~/Library/LaunchAgents/ru.hairid.bot.plist
```

Снять с автозапуска:

```
launchctl unload ~/Library/LaunchAgents/ru.hairid.bot.plist
```

## Если бот молчит

- В журнале `данные/журнал.log` строка **409 Conflict** значит, что запущено два бота
  сразу. Оставьте один: `pkill -f "node bot.mjs"`, потом запустите заново.
- Строка **ответы ИИ ВЫКЛЮЧЕНЫ** — не нашёлся ключ OpenRouter.
- В группе бот отвечает только на прямое обращение через `@hairidspb_bot` или на ответ
  на его сообщение. В личной переписке — на любое сообщение.
