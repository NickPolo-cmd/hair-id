## 3. Как это работает технически

**Никакой сборки, никакого npm.** Чистые HTML, CSS и JavaScript.
Открывается двойным щелчком по файлу.

### Выкладка

```bash
node tools/сборка-для-github.mjs https://nickpolo-cmd.github.io/hair-id/
git add -A && git commit -m "..." && git push
```

Сборка: складывает студию в корень `docs/`, магазин в `docs/shop/`, переписывает
все ссылки, сводит карты сайта, оставляет общие картинки в одной копии,
вырезает внутренние заметки и отсеивает всё, чего не должно быть на сайте
(белый список расширений). **Папку `docs/` руками не трогать** — она
пересобирается целиком.

### Ключевые скрипты

| Скрипт | Что делает |
|---|---|
| `сборка-для-github.mjs` | собирает `docs/` — запускать перед каждым push |
| `проверка-сайта.mjs` | **главная проверка**: все страницы, скорость, заказ. Сам поднимает серверы |
| `проверка-адаптива.mjs` | 80 проверок в настоящем браузере на 4 ширинах |
| `сверка-копий.mjs` | не разошлись ли общие файлы студии и магазина |
| `связка-услуга-товар.mjs` | один источник → страница услуг, карточки товара, шпаргалка |
| `статика-каталога.mjs` | вписывает карточки товаров в разметку (для поисковиков) |
| `цены-ориентиры.mjs` | пересчёт цен товаров |
| `товары-в-магазин2.mjs` | из прайса в данные каталога |
| `финмодель.mjs` | пересчёт бизнес-модели (закрытые числа в `бизнес/вводные.json`) |
| `сводка-учёта.mjs` | недельная сводка по заявкам из `marketing/УЧЁТ.csv` |

**Правило:** всё, что генерируется скриптом, правится в скрипте, а не в файле —
иначе следующий прогон затрёт правку.

### Как проверять работу

```bash
node tools/проверка-сайта.mjs
node tools/проверка-адаптива.mjs
node tools/сверка-копий.mjs
```

Для браузерных проверок нужно:
```bash
export PLAYWRIGHT_BROWSERS_PATH="$HOME/.cache/ms-playwright"
export PATH="/usr/local/bin:$HOME/.local/node/bin:$PATH"
```

## 4. Что нельзя делать

**Не должно попасть в публичный репозиторий** (он открыт, GitHub Pages
на бесплатном тарифе иначе не отдаёт сайт):

- `поставщик/` — контакты фабрик, закупочные цены, переписка
- `бизнес/` — финмодель, себестоимость, личный доход мастера
- `товары-цены.txt` — закупочные цены
- `site*/assets/photo/ИСТОЧНИКИ.md` и `ФАКТУРЫ-И-КОД.md` — там написано,
  что фотографии стоковые
- `ПРОВЕРКА-КОДА.md` — цитировал контакты фабрик

Всё это уже в `.gitignore`. **Перед добавлением нового файла с цифрами или
контактами — сначала в `.gitignore`, потом на диск.**

Файлы из `поставщик/` **не удалять** — они нужны владельцу, просто
не публикуются.

**Прочее:**
- `rm -rf` запрещён → `node /Users/nick/.claude/tools/trash.mjs <путь>`
- Каждую правку владельца дословно записывать в `ЖУРНАЛ-ПРАВОК.md` **до** работы
- Перед словом «готово» — таблица сверки: пункт → сделано → чем проверено
